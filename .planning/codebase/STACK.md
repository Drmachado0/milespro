## Configuration

- Vite injects `VITE_SUPABASE_URL`, `VITE_SUPABASE_PUBLISHABLE_KEY`, `VITE_SUPABASE_PROJECT_ID` at build time via `define:` block in `vite.config.ts:25-31` (with hardcoded fallbacks).

  - `VITE_SUPABASE_URL`, `VITE_SUPABASE_PUBLISHABLE_KEY`, `VITE_SUPABASE_PROJECT_ID` (Supabase)
  - `VITE_SUPABASE_SERVICE_ROLE_KEY` (optional, used by `supabaseAdmin` in `src/integrations/supabase/client.ts:7` — **dangerous to ship to client**, see CONCERNS)
  - `VITE_POSTHOG_KEY`, `VITE_POSTHOG_HOST` (PostHog mock — `src/main.tsx:7-10`)

- Edge functions read env via `Deno.env.get(...)`: `SUPABASE_URL`, `SUPABASE_ANON_KEY`, `SUPABASE_SERVICE_ROLE_KEY`, `LOVABLE_API_KEY`, `RESEND_API_KEY`, `GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET`, `ENCRYPTION_KEY`, `CRON_SECRET`. These are configured in the Supabase dashboard, not in `.env`.
