# Miles Pro Hub

Painel completo para gestão do mundo das milhas e pontos:
- Controle de milheiro e custo médio
- Simuladores de compra, venda, transferência e bumerangue
- Gestão de clubes de pontos e cartões
- Visão geral de promoções, alertas e relatórios

## Tecnologias principais

- React + TypeScript
- Vite
- shadcn-ui + Radix UI
- Tailwind CSS
- Supabase (dados/autenticação)
- Capacitor (versão mobile)

## Scripts

Usando `npm` (pode adaptar para `pnpm` ou `bun` se preferir):

```bash
# Instalar dependências
npm install

# Ambiente de desenvolvimento
npm run dev

# Build para produção (web)
npm run build

# Preview do build
npm run preview

# Lint (análise estática)
npm run lint

# Type-check (TypeScript strict, sem emitir arquivos)
npm run typecheck
